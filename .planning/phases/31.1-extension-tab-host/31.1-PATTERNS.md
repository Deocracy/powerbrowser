## Shared Patterns

- **Regenerate, never text-edit:** patch authorship via `git diff --no-index` from patched copies in a scratch tree (002a process precedent). Blob-hash non-vacuity is the tripwire.
- **End-of-file section + one routing line:** new boundary code in the end-of-file host section; existing lines change in place (Phase 27 precedent). Catalogue rows appended at END (`--fix` after every boundary edit, `--catalogue` after).
- **Derive-and-compare + `--self-test`:** every new static check derives at check time, compares as set equality, plants faults naming the drift, fails on empty derivation (stand-in gate + suggestions gate precedents).
- **Stage-before-trust:** `scan-brand-residue.mjs` iterates `git ls-files` — stage new `patches/` + `scripts/` files before trusting a green scan.
- **Loud refusal over silent wrong answer:** `addTab`/`removeTab`/`selectedTab=`/`tabs.create` refuse with the Phase-38/36 reason (002c step-13/14 precedent: silent `active:false` is worse).
- **Commit by explicit path only.** Never `-a`, `--amend`, `-A`, stash. Never stage `.planning/state.json`. Never touch `upstream/`.
