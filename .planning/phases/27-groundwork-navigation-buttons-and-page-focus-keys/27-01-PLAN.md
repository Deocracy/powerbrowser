<objective>
Lead the phase with one end-to-end tracer: with a web page focused and loading, Esc stops it. The key is
caught by a page-scoped chrome `<key>` row, relayed to the Theia frame as a `shortcut` push, routed by the
new push router to the one shortcut table, which sends the new `webTabStop` kind back to chrome, which
calls the overlay's `stop()`. Then make the Reload button that same single element showing Stop while
loading (NAV-01), and register the live check and the chrome-bar typecheck.

Purpose: proves on the first commit every layer the phase changes (boundary section, key rows and focus
tracker, push router, relay table, chrome-bar button, live harness) before later plans widen each one.
Follows the CONTEXT ruling (2026-10-20): a key that clashes with Theia takes the browser meaning only while
a web page has focus, so every page row is disabled whenever the Theia frame has focus (KEY-04 by
construction).

Output: one end-of-file section in the boundary file, the PAGE_KEYS mechanism with its first row, the
router, the relay, the Reload/Stop element, `scripts/lib/pb-live-probe.mjs`, `scripts/verify-nav-keys-live.mjs`,
three registry rows.
</objective>
