# Phase 30 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note.** This phase extends the pill and dropdown contracted in 29-UI-SPEC (which extends
13- and 27-UI-SPEC). Tokens, row geometry, the 432px panel, type, colour, the focus ring, motion,
the layer policy, the Esc sequence and the `{App}` / `{engine}` copy rules are inherited and are
not re-specified unless they change. It adds, for SMODE-01..06:

- the mode button and mode chip at the pill's left end, with its reset control
- the modes dropdown (Command centre, each engine, Bookmarks, Tabs, History, Actions, Search Settings)
- one result list per mode, including zero-query lists
- Command centre: Theia's quick-access picks rendered under the pill; `@` and `:` handed to Theia
- the "Go to {address}" row
- mode tokens, Accel+Up/Down, Alt+Up/Down, Backspace-at-start, and the address keys from Command centre
- the per-PowerBrowser-mode default table (D-03), with Browsing and Organising **PENDING-CHRIS**

Hard rules that bind every row below (inherited): no Theia core patch, no Firefox internal outside
`PowerBrowserAPI.sys.mjs`, no custom browser chrome beyond the chrome bar, no internal identifier
in user-facing text, product and engine names from configuration and engine data only.

Mode: `--auto` (Chris's standing autonomous rule). Every choice not fixed upstream is marked
**Decided (autonomous, recommended)** with its reason. The two default modes are **not** decided
here; see "Default mode per GUI mode".

**Visual mockups:** [30-MOCKUPS.html](30-MOCKUPS.html) in this directory renders every candidate
default at 1:1 pixels in 1200px-wide PowerBrowser windows, empty state and after typing "git",
plus the modes dropdown open, the chip anatomy, and the Coding default for reference.

## Spacing Scale

Inherited unchanged. Values are multiples of 4, except the inherited 12px `md-gap` step.

| Token | Value | Usage in Phase 30 |
|-------|-------|-------------------|
| xs | 4px | Pill left padding (changed, see below); gap inside the mode button; mode button right margin; modes-menu padding; separator vertical margin |
| sm | 8px | Chip horizontal padding; gap inside rows (inherited) |
| md-gap | 12px | Row horizontal padding (inherited); pill right padding (unchanged) |
| md | 16px | Icon slots (16×16); result-dropdown padding (inherited) |
| lg | 24px | Mode button / chip height; reset (x) hit area 24×24; heading and group-header row height |
| xl | 32px | Row height (inherited); modes-menu row height |
| 2xl | 48px | Command-centre row with a `detail` line (two lines) |
| 3xl | 64px | Not used |

**Geometry (Decided, autonomous, recommended):**

- **Pill padding** becomes `0 12px 0 4px`. The mode button is the first child, so it sits 4px
  inside the pill's left hairline; the 32px pill leaves 3px above and below a 24px button.
- **Mode button, Address form** (`.pb-address-mode`): 24px tall, `padding: 0 4px`, `gap: 4px`,
  radius 9999px, transparent fill. Contents: the default engine's icon (16px) and
  `codicon-chevron-down` at 12px glyph size, muted ink. `margin-right: 4px`, so with the pill's
  4px gap there is 8px before the lock or the text.
- **Mode chip** (`.pb-address-mode-chip`, every other mode): a 24px wrapper, radius 9999px,
  `--color-surface-raised` fill, holding two buttons:
  - `.pb-address-mode` — `padding: 0 4px 0 8px`, `gap: 4px`: mode icon 16px, label, chevron.
    The label is capped at `max-width: 160px` and ellipsizes.
  - `.pb-address-mode-reset` — 24×24, radius 9999px, `codicon-close` 16px, muted ink. Present only
    when the active mode differs from the PowerBrowser mode's default (D-14). When absent, the
    chip's right padding is 8px.
- **Modes dropdown** (`.pb-chrome-bar-dropdown.pb-address-modes`, D-10): anchored at the pill's
  left edge, `top: calc(100% + 4px)`, `width: 280px`, `padding: 4px`. Heading row 24px; item rows
  32px with `padding: 0 12px`, `gap: 8px`; separators 1px with `margin: 4px 0`. Same
  `max-height: min(432px, calc(100vh - <top> - 8px))` rule as the result dropdown.
- **Result dropdown**: unchanged (29-UI-SPEC). Per-mode row caps replace the single 10-row cap,
  see "Result lists by mode". Group headers (provider separators, Command centre) are 24px rows.
  A Command-centre row with a `detail` becomes 48px (title line 21px + detail line 18px + 4px
  top and bottom padding, rounded to 48).

Exceptions: none new.

## Copywriting Contract

Inherited rules: no internal identifier (no mode id, prefix name, provider id, command id, pref
key, port or raw exception) in user-facing text; `{App}` is `appSubject()`; `{engine}` is the
engine's display name read at render time; every error ends with a next step that is a real
affordance on screen; every new string lives in `CHROME_BAR_COPY` so
`verify-shell-error-copy.mjs` pins it by set equality. `{default}` is the label of the
PowerBrowser mode's default (from the D-03 table). Key names in copy (`{addressKey}`) come from the
derived shortcut table, never from `KeybindingRegistry`.

## Default mode per GUI mode

**D-03 (locked):** one table keyed by PowerBrowser mode id holds each default. Chris's answers are
a one-row change each. Planning may proceed; the task that fills the two rows is gated on his
answer and nothing hard-codes a value before it.

| PowerBrowser mode | Default | Status |
|-------------------|---------|--------|
| Coding | Command centre | **Decided** (Chris, 2026-10-20) |
| Browsing | — | **PENDING-CHRIS** (D-01) — candidates A–D below; recommendation **A Address** |
| Organising | — | **PENDING-CHRIS** (D-02) — candidates A–D below; recommendation **A Tabs** |
| Custom modes | Address | Decided (D-17) |

Facts every candidate shares, so the trade-offs compare like with like:

- **Idle pill.** Unfocused, the pill shows the active tab's address (a web tab's URL, an editor's
  resource URI). In Organising the active surface is the Panorama canvas, which has no address, so
  **the Organising pill is empty when idle and its placeholder is always on screen**. A non-Address
  default shows its chip permanently, beside the URL (D-13).
- **Focus.** Click, Tab, or Accel+Up/Down into the pill selects all text (inherited). Ctrl+L, Alt+D
  and F6 always enter **Address** mode whatever the default (D-28).
- **Zero-query list.** When the pill gains focus by click or Tab, or its text becomes empty, the
  dropdown opens with the active mode's zero-query list, if it has one, with **no row highlighted**,
  so Enter on an unedited URL still reloads it as in Phase 29. Address and engine modes have no
  zero-query list (top sites stay deferred), so they open nothing.
- **Layer rule (a).** Any open dropdown hides the active web page (`.pb-chrome-bar-dropdown` is in
  `BLOCKING_LAYER_SELECTOR`). Theia surfaces (editors, the Panorama canvas) are not web pages and
  stay visible. A default with a zero-query list therefore hides the page on every click into the
  pill.

## Interaction Contract (SMODE-01..06)

### Pill composition (left to right)

| Order | Element |
|-------|---------|
| 1 | **New:** mode button (Address form) or mode chip (every other mode), `.pb-address-mode` / `.pb-address-mode-chip` |
| 2 | Lock glyph (unchanged, secure pages only) |
| 3 | Input (unchanged ARIA from 29-UI-SPEC); `aria-label` follows the mode, see Copywriting |

Phase 29's code assumes nothing about the first child (29-UI-SPEC "Phase 30 boundary"), so the
insertion needs no Phase 29 rework. The pill moves into `address-bar/` first and unchanged (D-04),
with every Phase 29 gate green before any mode code lands.

### Mode button and chip (SMODE-03)

- **Click, Enter or Space on the mode button, or ArrowDown while it has focus:** opens the modes
  dropdown (Firefox). The results dropdown closes when the modes dropdown opens.
- **The x (reset) control:** one click returns to `{default}`, keeps the typed text, and re-runs
  the query. **Reading of criterion 1, for the verifier:** "one click on the chip returns to the
  mode's default" is one click on the chip's x. The chip body opens the dropdown, as Firefox's
  switcher does. Without that split, a non-default chip could not open the menu by mouse.
- **Backspace** with the caret at 0 and no selection, while the mode differs from `{default}`:
  returns to `{default}` and re-runs the query (D-14). When the mode already is the default,
  Backspace keeps its stock meaning.
- **Visibility (D-13):** Address shows the icon form with no label. Every other mode shows the
  chip. In Coding the "Command centre" chip is always shown. x shows only when the active mode
  differs from `{default}`.
- Hover: the mode button and chip body take `--color-surface-raised` (the chip, already raised,
  takes `--color-border`); x takes a `--color-border` circle. Transition 0.15s ease (inherited).
- Tooltips use `HoverService` with `pb-chrome-bar-hover` (inherited).

### Modes dropdown (SMODE-01)

Entries top to bottom (D-08), each a 32px item row with a 16px icon and a 14px label:

1. Heading "This time, search with:" (24px, caption, not focusable)
2. Command centre
3. separator
4. One row per visible engine, in `listSearchEngines` order (D-07); at this tree's
   `configuration.toml`, "DuckDuckGo Lite" and "Wikipedia"
5. separator
6. Bookmarks, Tabs, History, Actions
7. separator
8. Search Settings

- `role="menu"` with `role="menuitem"` rows; `aria-activedescendant` follows the highlight.
- **Alt+Up/Down** from the input, or the button gestures above, open it with the active mode's row
  highlighted (no row when the mode is Address). ArrowUp/Down move and wrap, skipping the heading
  and separators; Home/End go to the first and last item.
- **Access keys** (the underlined letter, see Mode labels): a unique letter picks immediately; a
  letter shared by several rows (an engine starting with B, C, T, H, A or S) moves the highlight
  through those rows and Enter picks.
- **Picking a mode row** enters that mode. The typed text is kept when it differs from the
  committed address; when the pill still shows the page's own address, the text is cleared, so
  the mode starts at its zero-query list (Firefox `#getSearchString`). Focus returns to the input,
  caret at the end.
- **Engine row with a modifier:** Shift+click or Shift+Enter searches the typed text with that
  engine now, in the current tab; Ctrl+click or middle-click does so in a new background tab
  (Phase 29 precedent). Neither changes the mode or the default engine.
- **Search Settings** opens Theia's preferences editor filtered to the default-engine setting,
  "Browser › Default Search Engine" (D-09), and closes the dropdown.
- **Esc** closes the modes dropdown and returns focus to the input; the mode is unchanged.
  Clicking outside closes it.
- The modes dropdown is a `.pb-chrome-bar-dropdown` layer, so layer rule (a) covers it with no new
  selector (D-10).

### Mode lifetime (D-15, D-16)

A picked mode lasts until Enter commits, Escape reverts (the second Esc of the inherited sequence,
which also restores the address), the active tab changes, or the PowerBrowser mode changes. Then
the pill returns to `{default}`. Coding keeps Command centre while a web tab is active.

### Tokens and keys (SMODE-04)

| Typed at the start, then a space | Outside Command centre | In Command centre |
|----------------------------------|------------------------|-------------------|
| `* ` / `% ` / `^ ` | Enter Bookmarks / Tabs / History; the token is consumed into the chip | Same |
| `> ` | Enter Actions; token consumed | `>` stays in the text and lists all Theia commands (VS Code) |
| `? ` | Enter the default engine's mode; token consumed | `?` stays; Theia's help provider lists the prefixes |
| `@alias ` | Enter that engine's mode; token consumed | `@` stays and hands off to Theia's symbol picker |
| `@` alone | Lists engines that have an alias; with none configured (this tree), plain text | — (as above) |
| `:` | Plain text | Hands off to Theia's go-to-line picker |
| `#` | Plain text (Firefox title restrict is not adopted) | Workspace symbols |
| `edt `, `term `, `task `, `debug `, `view ` | Plain text | That Theia provider |

- A token without a following space stays text (D-18). The table is derived at check time from the
  mode contributions and the registry and compared by set equality (D-33).
- **Accel+Up/Down** (D-19) cycles Address → each engine → Bookmarks → Tabs → History → Actions →
  Command centre → Address, without opening the dropdown, and re-runs the query with the current
  text. Both keys stop propagation. Bound only under `ADDRESS_FOCUSED_CONTEXT_KEY` (D-20).
- **Alt+Up/Down** opens the modes dropdown (above), also stopping propagation.
- **Decided (autonomous, recommended):** Firefox's "Tab past the last result focuses the mode
  button" is not adopted. The button precedes the input in DOM order, so Shift+Tab from the input
  reaches it natively, and Tab keeps Phase 29's autofill-accept meaning.

### Result lists by mode

Every list renders in the existing result dropdown with Phase 29's row anatomy (16px icon, title,
caption, trailing type marker, 32px). Highlight is tracked by row key. With typed text, the first
actionable row is highlighted by default; zero-query lists start with no highlight.

| Mode | Zero-query list | With text | Cap |
|------|-----------------|-----------|-----|
| Address | none (no dropdown) | Phase 29 unchanged | 10 (inherited) |
| Engine | none | Heuristic "Search with {engine}" row, then up to 4 of that engine's suggestions (when suggestions are on), then the one-off strip without that engine | 5 |
| Tabs | Every open tab except the active one, most recently used first | Go-to row (if the classifier matches), open tabs whose title or URL contains the text, trailing search row | none; scrolls |
| Bookmarks | 10 most recently added | Go-to row, matching bookmarks, trailing search row | 10 + Go-to + search |
| History | 10 most recent visits | Go-to row, matching history, trailing search row; Shift+Del works | 10 + Go-to + search |
| Actions | Every command in the "Browser" category that exists in this phase (D-11: Back, Forward, Reload, New Tab), in palette order | Matching actions; no Go-to, no search row | none; scrolls |
| Command centre | The file provider's picks for `''` (recently opened files) | See "Command centre" | none; scrolls |

- **Tabs rows** are Phase 29 open-tab rows ("Switch to Tab" caption, `codicon-browser` marker).
  The active tab is never listed (Firefox). Enter switches; Ctrl/middle-click and Alt+Enter follow
  Phase 29.
- **Bookmarks / History rows** are Phase 29 rows with their markers. Enter loads in the current
  tab; Alt+Enter and Ctrl/middle-click follow Phase 29.
- **Actions rows:** title = command label; trailing keybinding badge(s); Enter or click runs the
  command (D-7: these are UI-opening or navigation commands; no state-changing kind runs as a
  command id).
- **Trailing search row** (Bookmarks, Tabs, History only; **Decided, autonomous, recommended**):
  never highlighted by default unless nothing else matched; it sends nothing to the engine until it
  is chosen, and engine suggestions are never requested in these modes. Reason: a local mode that
  is a PowerBrowser default must not trap the user away from search, and the row costs no
  privacy because nothing is sent while typing.
- Places rows still arrive only through the Phase 29 kinds; favicons only as `data:` URIs.

### Command centre (SMODE-05, D-21..D-27)

- **Source:** picks come from `QuickAccessRegistry.getQuickAccessProvider(prefix)`, called with
  the text after the prefix, cancelled on each keystroke. The pill renders them; Enter or click
  calls the pick's `execute()` / accept.
- **Row anatomy:** leading 16px slot holds the pick's `iconClasses` (Theia's file-icon theme for
  files; empty for commands). Title = `label`. Caption = `description` (inline, truncates first).
  Trailing = `keySequence` as keybinding badges (12px caption, 1px `--color-border`, radius 4px,
  `padding: 0 4px`, 4px between badges). A pick with `detail` becomes a 48px row with the detail on
  a second caption line. Highlighted label ranges are **not** emboldened (weight rule).
- **Separators:** each provider separator becomes a 24px group-header row with its label in
  caption ink ("recently opened", "file results", "other commands"), with a 1px `--color-border`
  top rule except on the first group.
- **No search anywhere (D-26):** no engine heuristic row, no "Search {engine}" row, no one-off
  strip, no autofill, and the suggestion kind is never sent while the mode is Command centre.
- **Prefixes `@` and `:`** (D-23) call `quickInputService.open(text)`: Theia's centred quick input
  opens with the text, and the pill keeps its text. A prefix whose probe-7 check failed (D-22) does
  the same.
- **Reading of criterion 4's "page stays visible", for the verifier (D-27, locked):** Command
  centre shows its results **under the pill**, never as the centred stock quick-input (except the
  `@`/`:` hand-off and a D-22 fallback); the pill keeps its text, caret and IME state while results
  update; there is no engine suggestion row. The result dropdown itself hides an active **web
  page** under layer rule (a), exactly as Phase 29's does. Editors, terminals and other Theia
  surfaces are not web pages and stay visible behind it.

### Address from Command centre (SMODE-06)

- **Ctrl+L, Alt+D:** focus the pill in **Address** mode with the current URL selected, in every
  PowerBrowser mode. **F6 from outside the pill:** the same. **F6 inside the pill:** in Command
  centre (or any non-Address mode) switches to Address mode and keeps focus; in Address mode it
  keeps Phase 27's pass-to-page meaning (D-28). The planner confirms Alt+D is not bound by Theia
  when the pill or a web page has focus.
- **Go-to row (D-29):** when the text has no Command-centre prefix and the pure classifier beside
  `isCanonizable` says "unambiguous URL" (a scheme, `localhost[:port]`, `host:port`, an IP, a
  leading `www.`, or a trailing `/`), the first row is "Go to {address}", highlighted. Enter commits
  through `commitText` (Phase 29's fixup and http(s) wall, D-31). The same classifier gives the
  Go-to row in Tabs, Bookmarks and History.
- **Bare dotted names (D-30):** `README.md`, `main.py` and the like list file results first, then
  an unhighlighted "Go to {text}" row after them.
- **Enter with no highlighted row** (zero-query list on an unedited address): commits the pill text
  as Phase 29 does. In Command centre this happens only when the classifier says URL; otherwise
  Enter does nothing.
