Phase 30 — Address-bar default modes

Every frame below is a PowerBrowser window drawn at 1:1 pixels (1200 px wide, the real 40 px chrome bar, 32 px pill and rows, the real colours). On a narrow screen each frame scrolls sideways inside its own box rather than shrinking. Favicons are plain coloured squares; engines are this tree’s configuration.toml pair, DuckDuckGo Lite (default) and Wikipedia.

What Chris picks: one Browsing option (A–D) and one Organising option (A–D). Coding is already Command centre. Recommended: Browsing A (Address), Organising A (Tabs). Contract and trade-off tables: 30-UI-SPEC.md → “Default mode per GUI mode”.

Two rules shape every frame. (1) Unfocused, the pill shows the active tab’s address; in Organising the canvas has no address, so the pill there is empty when idle and its placeholder is always visible. (2) An open dropdown hides an active web page (layer rule a); Theia surfaces such as the editor and the Panorama canvas stay visible.

Browsing — candidate defaults (PENDING-CHRIS)

Browsing — Option A: Address and search (Firefox) Recommended

The pill is Firefox’s address bar: engine icon, no chip. Empty text opens nothing, so the page stays visible; typing gives Phase 29’s heuristic row, autofill, history, bookmark and open-tab rows, and the one-off strip.

Browsing — Option B: Tabs

The pill starts in Tabs mode: a “Tabs” chip sits beside every URL, and focusing the pill lists the other open tabs, hiding the page. Typing filters tabs; unambiguous URLs get a Go-to row; a trailing row searches the web.

Browsing — Option C: History

The pill starts in History mode: a “History” chip beside every URL; focus lists the ten most recent visits. Typing filters history; Go-to row and trailing search row as in B.

Browsing — Option D: Command centre

The pill is Theia’s command centre in Browsing too: a “Command centre” chip; focus lists recently opened files; typing searches workspace files, > runs commands. It never searches the web; only unambiguous URLs get a Go-to row.

Organising — candidate defaults (PENDING-CHRIS)

Organising — Option A: Tabs Recommended

Panorama has no address, so the Organising pill is empty when idle and its placeholder is always on screen: “Search tabs”. Focus lists every open tab across groups; the canvas stays visible because it is Theia, not a web page.

Organising — Option B: Address and search

The same pill as Browsing A. In Organising the idle pill is empty, so the address placeholder is permanently on screen; tabs need “% ” or the modes menu.

Organising — Option C: Bookmarks

The pill starts in Bookmarks mode: focus lists the ten most recently added bookmarks; typing filters them. Read-only in this milestone (no bookmark editing).

Organising — Option D: Command centre

Command centre in Organising: Panorama commands such as “New Group” are one “>” away, but the no-prefix list is workspace files, which have nothing to do with arranging tabs.
