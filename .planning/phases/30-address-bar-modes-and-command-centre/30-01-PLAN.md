<objective>
Move the address pill out of `chrome-bar-widget.tsx` into `address-bar/` (D-04, D-05) with no behaviour change, and keep every Phase 29 gate able to see the moved code. This is the first plan of the phase because D-04 locks the move ahead of any mode code, with every Phase 29 gate (`verify-address-bar-rows`, `verify-chrome-bar-suggestions`, `verify-address-bar-live`, `verify-web-tab-bridge`, `verify-shell-error-copy`, `verify-chrome-bar-placement`) green before mode code lands.

Task order (recorded): Task 1 makes the directory scans recursive before anything moves, because the move commit is otherwise red (the suggestions gate finds zero routed commits) or silently blind (the bridge gate never sees the privileged callers; Pitfall 2). Task 2 is the tracer: the move itself, proven end to end in the live shell. Task 3 re-points the live plants so the self-test still means something (Pitfall 5).

Reversibility (D-04, rated, not gated per the STATE.md standing rule): costly. About 11 scripts and one catalogue prose line are re-pointed.

Output: `address-bar/address-bar.tsx` (class `AddressBar`), `address-bar/address-bar-rows.ts` (moved), recursive gate scans with nested-directory plants, re-pointed live plants.

- Every bind is static at module load (D-50). The privileged store kinds (`removeHistoryEntry`, `readClipboardText`) run only from `address-bar/address-bar.tsx` event handlers; no command id or keybinding names a store kind (research D7).
- Overlay layer policy: every new dropdown or menu is a `.pb-chrome-bar-dropdown`-class portal (D-10); no new `BLOCKING_LAYER_SELECTOR` entry.
- Live runs: rebuild Theia first (`nix develop .#theia --command bash -c 'cd theia && yarn build'`, log to `"${TMPDIR:-/tmp}"`). The harness sets `MOZ_PURGE_CACHES=1`. At most four web tabs on the served `127.0.0.1` origin per session; further pages are served from `localhost`. No `.planning/` path literal in any script. No assertion on the absence of a request, push or log line unless the same session first showed the observer seeing a positive case. Every new scenario gets a plant in `PLANTS` that must go red naming its expected text. The context-menu Paste & Go focus failure recorded in 29 `deferred-items.md` is the known Phase 27 remoteness defect: re-run once, record it in the SUMMARY, never weaken the step.
