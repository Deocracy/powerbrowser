# Phase 34 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note.** This phase extends the strip built in 13/14/22 (`TabStripWidget`) and the pill/bar contracted in 27/29/30-UI-SPEC. Pill geometry, dropdown panel, tooltip/hover policy, occlusion rules, Esc sequence, and the `{App}` copy rule are inherited and not re-specified unless they change. It adds, for TAB-01..TAB-09 + BMK-07:

- the tab context menu (Reload, Duplicate, Pin, Mute, Bookmark, Bookmark All Tabs, Move, Close Others/Left/Right/Duplicates)
- in-strip drag reorder affordance
- middle-click close, double-click empty-strip new tab, link drop
- overflow scroll + List All Tabs chevron menu
- pinned tabs (icon-only, restart-persistent)
- multiselect + bulk actions
- hover preview card (thumbnail or text fallback)
- background-title attention mark

Hard rules that bind every row below: no Theia core patch, no Firefox internal outside `PowerBrowserAPI.sys.mjs`, no custom browser chrome beyond the chrome bar, no internal identifier in user-facing text, product names from configuration only (D-15).

Mode: `--auto` (Chris's standing autonomous rule). Every choice not fixed upstream is marked **Decided (autonomous, recommended)** with its reason.

## Spacing Scale

Inherited unchanged. Values are multiples of 4, except the inherited 12px `md-gap` step.

| Token | Value | Usage in Phase 34 |
|-------|-------|-------------------|
| xs | 4px | Tab internal gaps; icon-to-label gap; menu item icon gap |
| sm | 8px | Tab horizontal padding; preview card padding; attention dot offset |
| md-gap | 12px | Menu item horizontal padding (inherited) |
| md | 16px | Tab icon slot 16×16; close glyph hit area base |
| lg | 24px | Tab height 32px is 2×md; close hit area 24×24; List All chevron 24×24 |
| xl | 32px | Tab row height 32px; menu row height 32px |
| 2xl | 48px | Preview card min-height |
| 3xl | 64px | Not used |

**Geometry (Decided, autonomous, recommended):**

- **Tab row** (`.pb-tab-strip-row`): height 32px, `gap: 4px`, horizontal scroll (`overflow-x: auto`, `overflow-y: hidden`), scrollbar hidden until hover.
- **Tab** (`.pb-tab`): height 28px within the 32px row (2px top/bottom inset), `padding: 0 4px 0 8px`, radius 6px, `max-width: 192px`, `min-width: 96px` unpinned. Label ellipsizes (`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`).
- **Pinned tab** (`.pb-tab.is-pinned`): `width: 32px`, `padding: 0`, label hidden, icon centered; pinned block sits at the strip's start with a 1px separator after the last pinned tab.
- **Close affordance** (`.pb-tab-close`): 24×24 hit area, 16px glyph, `opacity: 0` until tab hover/active/focus-within (touch: always visible). Same pattern as 27-08 tooltips — no layout shift on reveal.
- **Attention dot** (`.pb-tab-attention`): 6px circle, `margin-left: 4px`, accent fill (see Color).
- **List All chevron**: 24×24 button pinned to the strip's end, visible only when the row overflows (`scrollWidth > clientWidth`).
- **Preview card** (`.pb-tab-preview`): 280px wide, `padding: 8px`, thumbnail 264×150 (16:9, `object-fit: cover`, radius 4px) when present; title 13px semibold one line; URL 12px muted one line. Anchored below the tab (`top: calc(100% + 4px)`), `z-index` above the bar but below nothing (it hides the overlay per D-11).
- **Menu**: inherits the bar dropdown/menu geometry (rows 32px, `padding: 0 12px`, `gap: 8px`, separators `margin: 4px 0`). No new menu component.

Exceptions: none.

## UI Considerations

State coverage (copy above is referenced, not restated):

- **Empty**: no tabs is impossible (the shell always holds ≥1 main-area widget); empty strip area = blank row with the double-click affordance.
- **Loading**: tab shows spinner icon-class (existing `codicon-loading` swap); menu Reload disabled while its tab loads? No — Reload stays enabled (reload-while-loading is a no-op re-issue); Stop is not a menu item.
- **Error**: lost-view tab renders the tab with a warning icon-class; menu items except Close stay enabled (reload re-issues the open).
- **Overflow**: chevron appears iff `scrollWidth > clientWidth`, re-evaluated on resize and on tab add/remove; the List All menu mirrors the strip order, pinned first, with icon + label + attention dot.
- **Zero-one-many**: menu adapts — single tab hides Close family except Close Tab; multiselect shows `N Tabs` rows; duplicate/close-duplicates disabled when there is nothing to act on.
- **Long text**: labels ellipsize at `max-width: 192px` (tab) and menu width; full label in `title`.
- **Pinned**: icon-only; tooltip keeps the full label (+ ` — Updated` when marked); pinned tabs never scroll out of view (pinned block is `position: sticky; left: 0`).
- **Multiselect**: selected tabs carry `.is-selected` (accent-tinted wash + focus-visible outline parity); Esc clears the selection; clicking a non-selected tab clears then activates.
- **Drag**: dragged tab carries `.is-dragging` (opacity 0.6); drop indicator is a 2px accent bar before/after the target tab; auto-scroll at 8px edge zones during drag.
- **Preview**: opens after 400ms hover dwell (Firefox parity), closes on pointer-leave/tab-switch/scroll; never opens for the active tab while its overlay is visible (it would hide the page for no benefit); skeleton while the thumbnail resolves.

Interaction contract (binds the plans):

1. Right-click (or Shift+F10 / context-menu key) on a tab opens the menu anchored at the pointer; the menu lists exactly the ROADMAP contract items, each disabled exactly when its predicate says so (predicates derived in the gate, D-04).
2. Drag within the strip reorders; drop index = first tab whose horizontal midpoint is past the pointer; the home pane's `TabBar` order follows (`insertTab` semantics); order survives tab switches and mode switches in-session.
3. Middle-click on a tab closes it (no clipboard paste — the strip consumes `auxclick` button 1); double-click on empty strip opens a new tab and focuses the pill.
4. Link/file drop on the strip opens the URL as a tab next to the drop position (`openInBackground` + move); non-URL text drops search via the pill path (not a new tab); `javascript:`/non-http(s) refused.
5. Scroll wheel (Shift+wheel and horizontal) scrolls the row; chevron opens List All Tabs; picking a tab activates it and scrolls it into view.
6. Pin toggles icon-only; pins restore after restart (same URLs, pinned first, order kept); unpin returns the tab to its unpinned position.
7. Ctrl/Cmd-click toggles selection, Shift-click extends from the anchor, click clears; bulk menu acts on the whole selection; selection clears when all selected tabs close.
8. Preview shows thumbnail (when settled) + title + URL; attention dot shows on background tabs whose title changed, clears on activation.

Layer policy (binds every plan): the tab menu and the preview card are blocking layers — both selectors are added to `BLOCKING_LAYER_SELECTOR`, overlays hide while either is open, hover tooltips stay `position: 'top'` and never extend over the page rect, and focus returns to the page on close when the page had it (Phase 27 focus rule).

## Accessibility

- Strip row `role="tablist"`, tabs `role="tab"` with `aria-selected`; pinned tabs add `aria-label="{label}, pinned"`; attention adds `", updated"`.
- Menu uses the stock menu renderer (keyboard navigable, Esc closes, arrow keys move).
- Close buttons keep `aria-label="Close {label}"`; preview card is `aria-hidden` (tooltip-equivalent, not a focus target).
- Focus-visible outlines on tabs, chevron, and menu rows; reduced-motion disables drag-image animation and preview dwell fade.
