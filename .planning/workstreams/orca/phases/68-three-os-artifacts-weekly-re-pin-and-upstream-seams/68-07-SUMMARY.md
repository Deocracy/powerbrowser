# Phase 68 Plan 07: Claude agent SDK out of orcad, loaded from ORCA_CLAUDE_AGENT_SDK_DIR Summary

orcad no longer bundles `@anthropic-ai/claude-agent-sdk` (seam 080). It imports the SDK only from the
package directory named by the generic variable `ORCA_CLAUDE_AGENT_SDK_DIR` (seam 070). OrcaService
sets that variable at every spawn to the pre-installed Theia extension's SDK copy, or to `""` when
Theia's `backend-settings.json` lists `powerbrowser.claude-agent-sdk` as disabled.

## Deviations from Plan

1. **[Rule 1 - Bug] The inside-the-directory test uses `realpathSync(dir)`, not `resolve(dir)`.** Found in Task 1. Node's resolver returns the real path of the entry, so a symlinked package directory, such as pnpm's layout or any symlinked seed, would always have been refused. The seam imports `realpathSync` from `node:fs`. A directory that does not exist still rejects, because realpathSync throws inside the try. 070 stays at 19 lines.
2. **[Rule 3 - Blocking] `scripts/verify-orca-agent-hooks.mjs` passes `claudeAgentSdkDir: ''`.** Found in Task 2. It is a third `buildOrcadEnv` caller (from 63-03) that the plan did not list. buildOrcadEnv now throws without the option, so the full-tier `orca-agent-hooks` row would have thrown. The change is one line. **This file is outside `files_modified`, so Task 3's diff-scope automated check is red, naming exactly this one file.** The coordinator should accept the file or move the change.
3. **[Rule 2 - Correctness] Versioned disabled ids count as disabled.** Theia reduces each stored id to its unversioned form on load (`PluginIdentifiers.toUnversioned`), so `powerbrowser.claude-agent-sdk@1.0.0` disables the extension. The OrcaEnv table has a row for this case.
4. **Three orca-service plant targets retargeted.** The plants "switch removed", "a PTY switch back" and "a ptyEndpoint option back" spell the fixed-name list and the buildOrcadEnv signature literally. They now name the new last fixed name and the new option list. All 27 plants still go red. Scenario A also requires the extension's SDK path when no settings file exists.
5. **Not done, to avoid a merge conflict:** the registry comment above `orca-service-live-self-test` still says "25 cases"; the self-test now has 26.
