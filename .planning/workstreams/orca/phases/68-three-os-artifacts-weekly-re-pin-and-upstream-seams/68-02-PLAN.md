<objective>
OVL-02 (ROADMAP Phase 68 criterion 1): the release-train clock dispatches a weekly re-pin that
moves the pin to the newest Orca tag, re-applies the seam patches, runs Orca's typecheck:web and
typecheck:node over PowerBrowser's added files and the brand scan, publishes a bump PR with
auto-merge armed when green, and stops with a tracking issue for a human when red. A planted
conflict and a planted type error each stop it, in a hermetic self-test.

Purpose: Orca ships about five releases a week; without an automated re-pin the pin falls behind
the stock mobile app and the upstream seams rot.
Output: rebase-orca.yml and rebase-orca.sh, the release-train wiring (tick, detector, replay call,
bump job, report), the --orca-select and orcaDue logic with fixtures, the --orcad-only probe, the
workflow rules, docs/RELEASING.md, 68-02-SUMMARY.md.

This plan runs ONLY in its Orca lane (see lane_brief). The new release-train jobs take effect only
when Chris pushes main; the first live weekly tick, the bump PR and the owner's approving review
are deferred verification for the end-of-milestone pass.
