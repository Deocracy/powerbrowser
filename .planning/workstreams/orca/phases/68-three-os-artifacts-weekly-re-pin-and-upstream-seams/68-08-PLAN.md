<objective>
BEXT-02 (Chris 2026-11-10, P68-39): uBlock Origin ships pre-installed and enabled as a Gecko
WebExtension at a pinned version and sha256, unmodified. The user can switch it off or remove it,
and its GPL-3.0 licence is in the third-party notices. The mechanism is Gecko's distribution
directory, which installs an add-on into the profile once, with no network, and never reinstalls
one the user removed. The enterprise-policy route cannot do that, because its install modes forbid
removal.

Purpose: the first instance of D-30's general rule on the browser side
(SEED-261110-preinstalled-extensions).
Output: the pin and staging helper, one staging line per package script, the endpoint rows,
verify-bundled-xpi.mjs with four registry rows, the Bundled extensions notices section and
inventory rows, a BUILD.md note, 68-08-SUMMARY.md.
