artifacts contain what Phases 60-67 built.

the three packaging scripts, the packaged-tree, packaged-live, macOS-merge and build-orca
portability checks, the magic-based natives universe, the Flatpak grant, the Windows Node path,
BUILD.md sections, 68-01-SUMMARY.md.

workspace on branch ServerDestroyer/v1.7-Orca-integration. Hosted Windows and macOS jobs cannot
run here: they are shape-checked by rows and plants, and their first real run is deferred to
the end-of-milestone pass after Chris pushes main.

in this wave. Each lane writes its own `# NEW (68-0N, ...)` block at the two anchors; the
coordinator (68-06) keeps all of them in merge order 03, 04, 01, 02.

guard step that runs `verify-licence-allowlist.mjs --rulings` is added here. It enforces P68-21's

release-shape rule.
