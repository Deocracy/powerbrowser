# Phase 68 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.
> Phase 68: Three-OS artifacts, weekly re-pin and upstream seams.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Hosted CI job to release artifact | The thin macOS and Windows Orca jobs build in unprivileged hosted jobs; the digest leaves each job only as a job output | Built Orca tree, SHA256SUMS digest |
| Artifact to packaging and signing jobs | Packagers and sign-windows read the Orca artifact as data and admit it against an out-of-band digest | Orca tree, node-pty prebuild, staged Node |
| Weekly re-pin bot to main | The read-only rebase-orca job builds and tests; the bump job only moves the pin and opens a PR that needs review | Upstream tag and commit values, notices file |
| Upstream Orca remote to the build tree | Pinned tag and commit fetched from the upstream remote; mobile protocol constants read from an unpinned tag | Source tree, protocol constants |
| Seam export to upstream accounts | Exported seam patches and issue or PR bodies, written locally, never pushed | Seam patch, issue and PR text |
| Bundled extensions to the profile | The agent SDK extension and the uBlock Origin XPI are staged, seeded into the profile and reinstallable over RPC | Extension bytes, profile directory, filter-list egress |
| Host live checks | Live rows and the container build share one host | Process identities, build resources |
