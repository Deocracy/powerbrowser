- New web-tab request kinds webTabAgent and webTabAgentStop, both routed by WEB_TAB_ACTION_KINDS to handleWebTabAction; new push kind agentControlChanged, sent through sendWebTabPush on PowerBrowserWebTabState.
- webTabOpen gains one optional field, agent, whose only accepted value is true (any other present value is a validation refusal). Chrome records entry.agent only when it creates the overlay; an already-open reply ignores the field (P66-06). An agent overlay gets the usercontextid attribute of the agent container before appendChild (P66-26).
- webTabAgent: { kind: 'webTabAgent', tabId, method, params }. method is a name from AGENT_METHODS; params is the automation command's params object as orcad sent it. Replies: { ok: true, kind, where: 'done', result } on success; { ok: true, kind, where: 'unknown-tab' } (no overlay with that id, which includes every stock-window tab); { ok: true, kind, where: 'not-agent-tab' } (an overlay created without the flag); { ok: true, kind, where: 'agent-stopped' } (after Stop); { ok: true, kind, where: 'failed', code } with code an Orca BrowserErrorCode or browser_no_dialog; { ok: false, reason: 'validation', message } for a malformed tabId, a method outside AGENT_METHODS or params that fail that method's validator.
- webTabAgentStop: { kind: 'webTabAgentStop', tabId } -> { ok: true, kind, where: 'stopped' | 'unknown-tab' | 'not-agent-tab' }. Sent only by WebTabWidget.agentStop(), which only the chrome bar's Stop click handler calls (P66-21, P66-22).
- agentControlChanged push: { kind: 'agentControlChanged', tabId, active, stopped } (booleans). active turns true when chrome serves a webTabAgent call for the tab (where done or failed) and false after 20000 ms with no call (Orca's ACTIVITY_IDLE_MS), on Stop and on close; stopped turns true on Stop and stays true for the tab's lifetime (P66-20, P66-22).
- webTabGeometry keeps its shape { tabId, x, y, w, h, visible }. For an agent widget that is not shown, the frontend sends visible false with the box of the widget's own tab area (non-zero w and h); chrome parks agent entries (visibility visible, zIndex -1, docShellIsActive false) and hides every other entry as today (A1).
