Replies: { ok: true, kind, where: 'done', result } on success; { ok: true, kind, where: 'unknown-tab' } (no overlay with that id, which includes every stock-window tab); { ok: true, kind, where: 'not-agent-tab' } (an overlay created without the flag); { ok: true, kind, where: 'agent-stopped' } (after Stop); { ok: true, kind, where: 'failed', code } with code an Orca BrowserErrorCode or browser_no_dialog; { ok: false, reason: 'validation', message } for a malformed tabId, a method outside AGENT_METHODS or params that fail that method's validator.

- webTabGeometry keeps its shape { tabId, x, y, w, h, visible }. For an agent widget that is not shown, the frontend sends visible false with the box of the widget's own tab area (non-zero w and h); chrome parks agent entries (visibility visible, zIndex -1, docShellIsActive false) and hides every other entry as today (A1).
