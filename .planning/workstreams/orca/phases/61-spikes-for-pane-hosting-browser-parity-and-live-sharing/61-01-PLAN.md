@CLAUDE.md

Research corrections that bind this plan (61-RESEARCH Summary items 1-4): the persisted
orca.web.workspaceSession.v1 key holds no tabs; a pane needs the web bootstrap and a hydrated
store, not a bare component; a single React copy needs externals; a PB web tab is a chrome-owned
xul:browser overlay, not an iframe.

Harness facts (verified in the tree): the Theia frame exposes window.theia.container, and
probe() from scripts/lib/pb-relaunch.mjs runs a page-realm body with get(name) over it
(get('ApplicationShell'), get('WebTabOpenHandler'), get('WebTabChannel')). orcad's static handler
sends no CORS, CSP or frame header and its WebSocket server has no Origin check
(orca/src/main/runtime/rpc/ws-transport.ts, static-web-client-handler.ts), so a classic script or
an iframe from the orcad origin loads in the Theia document, while a cross-origin ES module
import would be refused for lack of CORS.
</context>
