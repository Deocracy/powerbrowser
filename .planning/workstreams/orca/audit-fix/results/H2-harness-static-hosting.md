## Needs owner
- harness-static-hosting-11 (round 2): the honest steering rule reports nine names that orcad is given on purpose. They are listed in `DELIBERATE_STEERING` in scripts/verify-orca-service.mjs, which the clause compares as a set, so a new steering name is red and a dropped one must leave the list. The owner should confirm each is meant:
  - PATH selects every program a child runs by name.
  - HOME selects the config every shell, git, ssh and npm reads (~/.bashrc, ~/.gitconfig, ~/.ssh/config, ~/.npmrc).
  - SHELL selects the shell program that terminals and agents start.
  - XDG_CONFIG_HOME selects the config directory git and other tools read.
  - On Windows, in ORCAD_ENV_ALLOWLIST_WIN32: ComSpec (the command interpreter), PATHEXT (which extensions run as programs), USERPROFILE (the home, so the config tools read), LOCALAPPDATA (per-user app data and config) and SystemRoot (where programs and libraries load from).
