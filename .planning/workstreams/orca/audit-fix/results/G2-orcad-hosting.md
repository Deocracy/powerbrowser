## Handoffs
- G1a: `powerbrowser/shell/PowerBrowserAPI.sys.mjs`, add `PowerBrowserOrcaHosting.readLoopbackSocketTable()` for orcad-hosting-03. It is async, never throws, and resolves `{ tcp: string, uid: number|null }`. On Linux, `tcp` is the UTF-8 text of `IOUtils.read("/proc/net/tcp", { maxBytes: 1 << 20 })`, the explicit maxBytes that readProcessStartTicks already uses for procfs, and `uid` is the first number on the `Uid:` line of `/proc/self/status`. Elsewhere, or on any failure, it resolves `{ tcp: "", uid: null }`. ## Behaviour changes
- orcad-hosting-01 (extends D-07 to the crash case): a PowerBrowser crash, SIGKILL or OOM kill now ends orcad, its terminal daemon and every agent within the 3 s grace plus orcad's own stop. Before, they ran until the next launch. orcad's command line gains a `--import data:` preload. Revert with 013fa4bd.
- 62-WR-01 / orcad-hosting-08: a refused or timed-out orcad start now ends the daemon that orcad started. Revert with 013fa4bd.
- 62-WR-04 (D-07; overturns P67-06's "reaps as the launch path does", a Claude's-pick item): Restart Orca from the failure page now keeps the adopted daemon and its running agents. Revert with 48742382.
- 62-WR-02: a quit granted while Theia is starting no longer starts orcad. Orca's quit observer is now registered before Theia's, so the order in which the two observers run is reversed. Revert with 54f56f23.
- orcad-hosting-07: an orcad that exits after ready 5 times within 5 min now ends on the failure page with Restart instead of restarting forever, and the second and later restarts wait 500 ms to 5 s. The new pref is `powerbrowser.orca.crashWindowMs`. Revert with ff4ca9ff.
- orcad-hosting-06 / pairing-credentials-03 / 62-WR-05 / 62-WR-03: hand-off files are removed at Theia's start, on an unexpected orcad exit, before a Restart and on a ready line with no offer. A frontend waits for the fresh offer instead of booting on a stale one. Revert with 5aaea085 and ff4ca9ff.
- 62-WR-06: on macOS and Windows, Orca can now get past the alias step, and seven Windows environment names reach orcad. Revert with 4b4ce028.
- 67-CR-01: the orcaStatus reply carries a `generation` integer. Revert with 2bd9ff07.
- orcad-hosting-03: a new diagnostics row "Orca port holder", once G1a's function lands. Revert with 2bb017ec.
