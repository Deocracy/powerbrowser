## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dispatcher input → job shell | `inputs.sha` comes from the owner or the train and reaches bash in `build-linux` |
| same-repo branch → self-hosted runner | any pushed branch can name the legion label; the pre-job hook (plan 49-02) is the runner-bound control |
| build artifact → hosted sign job | tarball, MAR and manifest cross from the unprivileged legion host into the only job holding signing material |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
