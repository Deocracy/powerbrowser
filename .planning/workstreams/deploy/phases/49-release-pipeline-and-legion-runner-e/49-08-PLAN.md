# 49-08: delete the release artifacts after the publish (G-49c, INF-04)

## Objective

The per-release artifact cap (500 MB) relies on `retention-days: 1` plus deletion after publish
(docs/BUILD.md INF-04 row, owner-pending numbers). Only the retention half exists. Add the deletion as
its own least-privilege job so sign-publish, which holds the signing secrets, gains no `actions: write`.

## Tasks

### Task 1: purge-artifacts job

- **files:** `.github/workflows/release.yml`
- **action:** job `purge-artifacts` (needs sign-publish, `if: needs.sign-publish.result == 'success'`,
  ubuntu-latest, `actions: write` only) with one step: for each name in `PURGE`, list this run's
  artifacts, DELETE each id, then require zero left.
- **verify:** `node scripts/verify-workflows.mjs && node scripts/verify-workflows.mjs --self-test`
- **acceptance_criteria:** green.

### Task 2: release-shape rule purge

- **files:** `scripts/verify-release-shape.mjs`, `scripts/verify-platform.sh` (comment)
- **action:** rule 11 as in must_haves; plants: job removed, a contents: write grant, the manifest
  artifact added to PURGE, the tarball artifact removed from PURGE, the remaining-count check removed.
- **verify:** `node scripts/verify-release-shape.mjs --self-test`
- **acceptance_criteria:** each plant red naming `purge`.

Ends with `node scripts/generate.mjs` and `scripts/verify-platform.sh --quick` green except the known reds.
