# 49-06: emit the Linux complete MAR in package-linux.sh (G-49a)

## Objective

`build-linux` uploads `objdir-release/dist/*.complete.mar` with `if-no-files-found: error`, but
`package-linux.sh` writes only the tarball and the manifest, so the first real release fails at the
upload. Add the Phase 45 MAR emit (`make_full_update.sh` against the staged release dir, the same
call `package-macos.sh` and docs/BUILD.md use) to the packaging script, and a release-shape rule
that goes red if the emit is removed while the upload still expects it.

## Tasks

### Task 1: emit the MAR

- **files:** `powerbrowser/packaging/package-linux.sh`
- **action:** after the tarball rewrite, remove stale `*.complete.mar` in `$OBJ/dist`, require
  `$OBJ/dist/host/bin/mar`, run `make_full_update.sh "${TARBALL%.tar.xz}.complete.mar" "$STAGE"`
  from `upstream/` with `MAR`, `MOZ_PRODUCT_VERSION=$VERSION`, `MAR_CHANNEL_ID=$MAR_CHANNEL`;
  remove the partial file and fail on error; require a non-empty result.
- **verify:** `bash -n powerbrowser/packaging/package-linux.sh`
- **acceptance_criteria:** syntax clean; the MAR name is `<app>-<version>.en-US.linux-x86_64.complete.mar`.

### Task 2: release-shape rule mar-emit

- **files:** `scripts/verify-release-shape.mjs`
- **action:** when a build-linux upload path ends in `*.complete.mar`, find the build-linux run step
  naming `powerbrowser/packaging/<x>.sh`, read that script, and require a `make_full_update.sh`
  invocation whose output names `.complete.mar`. Plant: the script with the invocation removed.
- **verify:** `node scripts/verify-release-shape.mjs && node scripts/verify-release-shape.mjs --self-test`
- **acceptance_criteria:** green; the plant goes red naming `mar-emit` and the script path.

Ends with `node scripts/generate.mjs` and `scripts/verify-platform.sh --quick` green except the known reds.
