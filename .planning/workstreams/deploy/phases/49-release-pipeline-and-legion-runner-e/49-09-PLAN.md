# 49-09: sign-windows reports skipped when AZURE_CLIENT_ID is unset (G-sign, R14)

## Objective

Azure Trusted Signing is out of scope (R14), so the six `AZURE_*` variables will never be set, and
the configuration gate makes `sign-windows` fail on every release that builds Windows. Keep the code,
but have the job report skipped when the account is absent.
