# 49-07: run the packaged rows and install-matrix in build-linux (G-49b)

## Objective

Plan 49-01 says build-linux runs the packaged rows, but no step invokes them, and the Linux
install matrix exists only as untracked 08-05 proof tooling. Promote the matrix to a tracked full
row with a self-test, register both, and run the packaged rows plus install-matrix in build-linux
before any artifact is uploaded.

## Tasks

### Task 1: install-matrix row and self-test

- **files:** `scripts/verify-install-matrix.mjs`, `scripts/verify-platform.sh`
- **action:** driver `runMatrix({tarball, binName, stock, waitMs, ...})` over the cells; full row reads
  `packagePath()` and `PB_STOCK_FIREFOX` (or `firefox` on PATH); self-test over fixtures. Register
  `install-matrix` in the full tier beside the packaged rows and `install-matrix-self-test` in quick.
- **verify:** `node scripts/verify-install-matrix.mjs --self-test`
- **acceptance_criteria:** control green; plants (two top dirs, absent binary, early exit, no
  screenshot, fork dies during the stock run, `.powerbrowser` residue, `.mozilla` residue, an unknown
  BUILD.md cell, no stock browser) each red naming the cell.

### Task 2: build-linux step and release-shape rule

- **files:** `.github/workflows/release.yml`, `scripts/verify-release-shape.mjs`
- **action:** one gated step after "Package the tarball..." that resolves a stock Firefox from the
  flake's nixpkgs and runs the six labels; release-shape rule `packaged-rows` with plants.
- **verify:** `node scripts/verify-release-shape.mjs --self-test && node scripts/verify-workflows.mjs --self-test`
- **acceptance_criteria:** green; plants (label removed, unknown label, step moved after the upload) red.

Ends with `node scripts/generate.mjs` and `scripts/verify-platform.sh --quick` green except the known reds.
