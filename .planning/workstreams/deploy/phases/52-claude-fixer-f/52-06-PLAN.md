# 52-06: OWNER_LOGIN for the fixer derive guard and the fix-pr assignee (gap G-52, R11)

## Objective

`github.repository_owner` is the organisation login (`Deocracy`). The fixer guard compares the
base-commit author and the dispatching actor against it, and fix-pr assigns the PR to it. Both need
the owner's user login. Owner ruling R11: use the repository variable `OWNER_LOGIN`
(value `ServerDestroyer`, set by the owner). FINISH-PLAN cites lines 178 and 1619; on main today
the two sites are release-train.yml:245 (derive, fixer-inputs step) and :1861 (fix-pr publish step).

With the variable unset the expression yields an empty string. The guard must then refuse, not
admit: `fixerDispatch` compares `f.author !== f.ownerLogin`, which admits an empty author when the
owner login is also empty.
