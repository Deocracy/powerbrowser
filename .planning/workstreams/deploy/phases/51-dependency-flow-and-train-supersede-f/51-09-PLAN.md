# 51-09: Split renovate-licensing so branch code never runs with the App token

## Objective

51-08 regenerated the notices by running the Renovate branch's own scripts in the job that then held the App token.
Split it into a credential-free generate job that runs only the trusted checkout's code over the branch's data files,
and a publish job that runs nothing from the branch tree.

## Tasks

1. `release-train.yml`: `renovate-licensing` becomes the generate job; new `renovate-licensing-publish` holds the token.
2. `publish-bump-branch.sh`: optional third argument, the expected remote tip; the compare also lists committer addresses.
3. `release-train.mjs` `publishPlan`: `expectTip`; committer addresses checked with author addresses; three plants.
4. `verify-workflows.mjs` rule `renovate-job`: the generate and publish shapes; fifteen new plants, four re-anchored.
5. `docs/RELEASING.md`, `.github/renovate.json5` header, BLOCKED.md item 18, 51-08-SUMMARY.md pointer.

## Verification

- `node scripts/verify-workflows.mjs` and `--self-test`; `zizmor`, `zizmor-self-test`, `renovate-config` rows.
- `node scripts/release-train.mjs --self-test`.
- `node scripts/generate.mjs`, `scripts/verify-platform.sh --quick` (known red `fixer-isolate-self-test` only).
