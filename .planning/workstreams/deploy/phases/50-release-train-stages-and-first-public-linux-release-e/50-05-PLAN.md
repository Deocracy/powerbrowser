# 50-05: withdraw.yml and the immutable-release probe (G-50, REL-02, R13 prerequisite)

## Objective

Carry 50-03 Task 1 to code: the withdraw workflow and the probe workflow, staged in `docs/` for the
owner to land in `powerbrowser-updates`, the runbook and verdict line in `docs/RELEASING.md`, and a
check that runs their shell. 50-03 itself stays open: Task 3 (the live probe) is the owner's.

Interpretation recorded: immutability applies only once a Release is published, so the probe
creates `probe-1` as a draft and then publishes it (never as latest). A draft-only probe would test
nothing. The published `probe-1` carries no release manifest, which `verify-descriptor-monotonic`
refuses today; Task 2 limits that check to release-key tags.

## Tasks

### Task 1: the two staged workflows and the runbook

- **files:** `docs/withdraw.yml`, `docs/release-probe.yml`, `docs/RELEASING.md`
- **action:** as in must_haves. Pins copied from `.github/workflows/release.yml`.
- **verify:** `node scripts/verify-channel-live.mjs --self-test` (unchanged) and Task 3's row.
- **acceptance_criteria:** `grep -c Withdraw docs/RELEASING.md` >= 3; `grep -c 'no-update only' docs/RELEASING.md` >= 1; one verdict line.

### Task 2: descriptor-monotonic ignores non-release-key tags

- **files:** `scripts/verify-descriptor-monotonic.mjs`
- **action:** skip a Release whose `tag_name` fails `RELEASE_KEY_RE`; control: a published `probe-1` with no manifest stays green; the existing release-key-without-manifest plant stays red.
- **verify:** `node scripts/verify-descriptor-monotonic.mjs --self-test`

### Task 3: withdraw row

- **files:** `scripts/verify-withdraw.mjs`, `scripts/verify-platform.sh`
- **action:** quick rows `withdraw` and `withdraw-self-test`. Plants: a mode input, an unpinned uses,
  input text in run:, a DELETE, the flag sent on a notes-only verdict, the flag not sent on a flag
  verdict, the marker dropped, the marker appended twice, an unknown verdict accepted, a target
  missing from the writes, a probe tag inside the ruleset pattern, the probe published as latest,
  two verdict lines in RELEASING.md.
- **verify:** `node scripts/verify-withdraw.mjs --self-test`

Ends with `node scripts/generate.mjs` and `scripts/verify-platform.sh --quick` green except the known reds.
