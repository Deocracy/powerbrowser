# 48-07: keep the Gecko telemetry server pref blank (IN-04)

## Objective

At any level other than `off`, the generator repointed Gecko's `toolkit.telemetry.server` at
the `[telemetry]` endpoint, which is the events Worker (48-REVIEW.md IN-04). Unified telemetry
is compiled out, but if any Gecko ping path were ever enabled it would send non-error pings to
the error endpoint. Owner ruling (FINISH-PLAN section 2): keep the Gecko pref blank, which
removes the path instead of asserting around it.

## Tasks

### Task 1: blank the pref at every level

- **files:** `scripts/generate.mjs`, `powerbrowser/branding/{dev,release}/pref/firefox-branding.js`
- **action:** in `mozillaEndpointPrefs`, set the server value to `''` unconditionally; keep the
  level validation. Update the doc comment, the emitted pref-file comment, and the
  `endpointHostsControl` level-all expectation (`''`). Run `node scripts/generate.mjs` and copy
  the two regenerated branding pref files over the tracked copies.
- **verify:** `node scripts/generate.mjs --check && node scripts/generate.mjs --self-test`
- **acceptance_criteria:** both green; a temporary restore of the repoint turns the
  `manifest endpoint hosts ...` self-test case red.

### Task 2: check the blank at every level

- **files:** `scripts/verify-telemetry.mjs`
- **action:** check 5 iterates the manifest level plus the sender's exported
  `TELEMETRY_LEVELS` (derived from the tree, not a kept list) and fails naming the level when
  the derived server is not blank.
- **verify:** `node scripts/verify-telemetry.mjs && node scripts/verify-telemetry.mjs --self-test`
- **acceptance_criteria:** green; a temporary restore of the repoint turns check 5 red naming
  `toolkit.telemetry.server`.

### Task 3: gates

- **verify:** `node scripts/generate.mjs && scripts/verify-platform.sh --quick`
- **acceptance_criteria:** green except the known reds `permission-prompts`,
  `permission-prompts-self-test`, `fixer-isolate-self-test`.
