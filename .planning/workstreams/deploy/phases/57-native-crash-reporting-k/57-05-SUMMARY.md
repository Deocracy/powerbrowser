  `Status: locked`) in the tracked `powerbrowser/distribution/policies.json`. All three package scripts copy that file
  verbatim, and the Nix repack only adds `DisableAppUpdate`.
- The lock is a policy, not a branding pref, for two reasons: D-84 keeps every branding pref unlocked, and the

  generated byte moved. B6's "gate over generate --check" does not apply, because the generator does not emit this key.

  `autoSubmit` getter in upstream `ContentCrashHandlers.sys.mjs` and checks the policy engine's `allowedPrefixes`.

  `fixer-isolate-self-test`.
