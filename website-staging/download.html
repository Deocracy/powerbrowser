powerbrowser-linux-x86_64.tar.xz

The download link always points at the latest release. The file name follows the stable asset-name form.

Checksums

Download SHA256SUMS from the same release and check the archive against it:

sha256sum --check --ignore-missing SHA256SUMS

Verify the attestation

The attestation covers the upload rather than the build host. It shows that the release workflow of this repository published these exact bytes. It does not cover the build host that produced them.

gh attestation verify powerbrowser-linux-x86_64.tar.xz --repo Deocracy/powerbrowser

The gh tool needs a GitHub login before it can verify online. Run gh auth login once on the verifying machine.

Offline alternative: on a machine that cannot reach GitHub, save the attestation bundle for the archive and pass it with --bundle:

gh attestation verify powerbrowser-linux-x86_64.tar.xz --repo Deocracy/powerbrowser --bundle <bundle-file>

Signing status

  • Linux x86_64: the archive is not signed with a platform code-signing key. Check it with SHA256SUMS and the attestation.
  • Windows: no build is published yet. The planned build is unsigned.
  • macOS: no build is published yet. The planned build is ad-hoc signed and not notarized.
