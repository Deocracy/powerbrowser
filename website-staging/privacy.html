Privacy

Error reports (off by default)

PowerBrowser sends an error report only if you turn error reporting on. Error reporting is off until you choose to enable it. When it is on, each report carries exactly these seven fields:

  • type: the kind of error.
  • basename: the file name of the code that raised the error, without its folder.
  • line and column: the position of the error in that file.
  • version: the PowerBrowser version.
  • buildID: the build identifier of this installation.
  • OS: the operating system name and version.

A report never includes the error message or the stack trace.

Retention

Error reports are kept for 30 days.

Who processes reports

Cloudflare is the only processor of error reports. No other company receives them.

Hosts the browser may contact without your action

PowerBrowser may contact these hosts without a click from you:

  • firefox.settings.services.mozilla.com, content-signature-2.cdn.mozilla.net, firefox-settings-attachments.cdn.mozilla.net: Remote Settings, which supplies filter lists, certificate revocation data and other configuration.
  • safebrowsing.google.com, safebrowsing.googleapis.com: Google Safe Browsing, which checks pages against known malicious sites.
  • updates.powerbrowser.org: checks for PowerBrowser updates.
  • release-assets.githubusercontent.com: downloads update files.
  • update.googleapis.com, www.google.com, dl.google.com, edgedl.me.gvt1.com: the Widevine content decryption module, which is checked for updates and downloaded when needed for protected media.

The browser also talks to a service on this computer. That traffic does not leave the machine.
