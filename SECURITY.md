# Security policy

## Reporting a vulnerability

Report a suspected vulnerability privately. Do not open a public issue, a bug report or a discussion for it.

1. Preferred: open the **Security** tab of this repository, choose **Report a vulnerability**, and fill in the form. Only the maintainers can see the report.
2. Alternatively, email **security@powerbrowser.org**.

Include:

- the PowerBrowser version, from the About dialog
- your operating system and how PowerBrowser was installed
- the steps that show the problem, and what you expect an attacker could do
- any proof of concept, kept to what is needed to reproduce it

Do not send passwords, tokens or private keys. If one of them is part of the problem, describe its kind and where it appeared, and leave the value out.

## Supported versions

Only the latest release receives security fixes. Update to the latest release before you report a problem that an older release may already have fixed.

## What to expect

- We acknowledge your report within 5 business days.
- We tell you whether we can reproduce it, and what we plan to do.
- We tell you when a fix ships. We do not promise a fix date in advance, because the timing depends on how severe the problem is.

If you do not hear from us within the acknowledgement window, send the report again to security@powerbrowser.org and mark the message as a second attempt.
