# Known issues

This page lists the problems that are known and not yet fixed. Each entry gives the problem in plain words and a workaround where one is safe to use. A workaround never turns off a safety check, a signature check or the update path.

## No public release yet

PowerBrowser has not published a first public release, so there is no installer to download and no update to install.

- **Workaround:** none needed. Watch the release notes for the first Linux release.

## Windows and macOS builds are not available yet

The first public release covers Linux only. Windows and macOS builds come in later releases.

- **Workaround:** none for now. Use the Linux build when it is published.
