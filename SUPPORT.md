# Getting help with PowerBrowser

Pick the channel that matches what you need.

- **A question, or help using PowerBrowser:** start a discussion at [Discussions](https://github.com/Deocracy/powerbrowser/discussions). Maintainers read Discussions, but replies are not guaranteed within a fixed time.
- **Something that does not work as documented:** open a bug report. On the **Issues** tab, choose **New issue**, then **Bug report**.
- **A feature you would like:** open a feature request from the same **New issue** page.
- **A suspected security problem:** do not use the issue forms or Discussions. Follow [SECURITY.md](SECURITY.md).
- **A problem that is already known:** check [docs/KNOWN-ISSUES.md](docs/KNOWN-ISSUES.md) first. It lists each known problem and any workaround that is safe to use.
